# Professor João Assis

Personal site and student hub. Static files, hosted on GitHub Pages.

## Publishing a material for Colégio São Benedito
1. Put the file in `students/sao-benedito/files/<grade>/` (grades: `6ano 7ano 8ano 9ano 1em 2em 3em`).
2. Add one entry to `students/sao-benedito/materials.js` (the format is explained at the top of that file).
3. Commit and push. GitHub Pages updates the site in about a minute.

Direct link for one grade: `https://professorjoaoassis.github.io/students/sao-benedito/#8ano`

## Changing page text
Pages are generated by `tools/build.py` (shared header, footer, English text with `data-pt` Portuguese versions).
Edit the text there and run `python3 tools/build.py`.
